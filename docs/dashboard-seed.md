# Welcome to your workspace

This note is your workspace's **dashboard** — the page you land on first. Edit it however you like; whatever you write here replaces this starter content for *this* workspace only. New workspaces created later will again start from this file.

## What you can do here

- Type `/` on an empty line to insert a block — headings, images, tables, code, and more.
- Drag blocks by their handle to reorder them.
- Turn any object into the dashboard from its `···` menu, or point it back here.
